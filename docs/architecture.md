# 架构说明

## 目标

本服务用于承接软件客户端的配置导出与导入请求，不提供网页界面，也不面向终端用户直接操作。

## 运行架构

- Cloudflare Workers：负责请求接入、鉴权、参数校验、业务编排和响应输出
- Cloudflare D1：负责保存配置正文、分享短码、客户端应用信息和审计日志
- Hono：负责组织路由、中间件和错误处理

## 核心链路

### 导出配置

1. 软件客户端读取当前本地配置
2. 客户端通过 `x-api-key` 调用导出接口
3. Worker 校验 `API Key`、请求结构和配置大小
4. Worker 将配置正文写入 D1，并生成分享短码
5. Worker 返回短码给软件

### 导入配置

1. 用户在软件中输入短码
2. 软件调用导入接口
3. Worker 校验短码并查询 D1
4. Worker 返回完整 JSON 配置
5. 软件自行决定覆盖或合并本地配置

## 设计约束

- 单份配置默认不超过 `256KB`
- 短码固定为 16 位大小写英文字母
- `API Key` 只存哈希值
- 短码默认永久有效
- 首版不实现配置更新、删除和后台管理端
