# Cloudflare 版本实施摘要

## 当前版本结论

项目已切换为全程运行在 Cloudflare 平台上的方案：

- 运行时：Cloudflare Workers
- API 框架：Hono
- 数据库：Cloudflare D1
- 接入对象：软件客户端

## 核心能力

- 软件调用 `POST /api/v1/config/export` 导出完整配置并获取短码
- 软件调用 `POST /api/v1/config/import` 根据短码导入完整配置
- 客户端通过 `x-api-key` 完成鉴权
- 配置正文直接保存在 D1 中
- 单份配置默认限制为 `256KB`
- 短码固定为 16 位大小写英文字母

## 与旧方案的差异

以下旧设计已经废弃：

- Fastify
- PM2
- PostgreSQL
- Redis
- Linux 单机部署
